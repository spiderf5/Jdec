# M2 字节级往返与坏类隔离（改写底座）

## 可观测形态（字节码 / 容器层面）

类文件是带长度前缀的属性序列：magic、次 / 主版本号、常量池计数、逐项  
常量池、访问标志、字段 / 方法表、属性表。`parse → 重汇编 → 逐字节相等`  
是可测的容器级事实。坏类 / 不可解码类表现为 magic 错误、常量池索引越界、  
Code 数组长度截断或属性长度溢出；multi-release / 截断类会让整批 parse 在  
某一条目抛错。特征是结构层面的，与语义无关，不含任何混淆器实现代码。  

## 本工具的支持项

对整份真实 jar 逐类执行 `ircheck`：parse → 重汇编 → 逐字节比对，报告  
「类相等数 / 总数」与「Code 数组相等数 / 总数」，并单列 unreadable 类数。  
坏类被隔离（单列报告、不拖垮整批），而非把整批判失败。输入条件是 jar  
可被 `zipfile` 枚举、类无 `jsr/ret`；产出是逐类相等统计与隔离清单。它是  
M1 等改写能力的底座，只证明字节可往返，不证明语义等价。  

## 已知不覆盖

- 不进行语义等价性证明；逐字节相等 ≠ 行为等价。  
- `jsr/ret` 与不可解码类按边界拒绝，不尝试猜测修复或补全。  
- 不处理加密容器或自定义 class 变体（非标准常量池标签 / 属性）。  
- 不比较不同 JVM 版本对同一类的 StackMapTable 重算差异。  

## 独立样本与可测点

| 语料 | 可测点 |
| --- | --- |
| `HMCL-3.15.2.exe` | 类相等数 / 总数、Code 数组相等数 / 总数、unreadable 数、result=PASS |
| `NeoRaven1.1.jar` | 同类往返统计在 PK jar 上的一致性、坏类隔离清单 |

## 独立金标准

不取 `ircheck` 自身输出。用 `zipfile` 取出每个 class 条目的原始字节序列，  
用一个独立的 class 文件解析器（按 magic / minor / major /  
constant_pool_count / 属性长度前缀）重新切分，并与重汇编产物逐字节比对；  
用 `javap -v` 独立核对常量池与属性计数。真值问题是「原始条目字节与重汇编  
字节是否一致」，不是「ircheck 报了 PASS」。  

## 负控（构造方式与预期失败）

构造 A：把某个 class 文件在 Code 属性中间截断（截断类，与仓库内  
`src/tests/sample.jar` 同类做法），放进 jar。预期 `ircheck` 报 unreadable ≥ 1  
或明确非 PASS，绝不能报干净 PASS。构造 B：翻转一个类的单字节常量。预期  
该类的逐字节比对必须失败、被隔离，且其余类仍各自比对、整批不被一票否决。  
两者证明相等门禁与隔离逻辑不恒真。  

## 与 03 阶段、独立研究线的边界

03 的 `behave` 行为对拍是语义级验收，本类是字节级底座，二者不等价、不互相  
替代；03 交付的是 Java 级 SecurityManager 沙箱 + 进程级外层，不是用户 /  
容器级 OS 边界（`ROADMAP:223-227`）。加密容器还原、自定义 class 变体属  
`ROADMAP:231-236` 独立研究线（JNIC 容器还原），永不并入通用恢复承诺，本清单  
不把它们算 1.0 默认支持项。当前独立语料无加密容器，该目标数为 0，只如实  
报告 0，不记为已攻克。
